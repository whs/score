## รูปแบบข้อมูลรับเข้า

ข้อมูลรับเข้าของโปรแกรมเป็นไฟล์ .csv (สามารถใช้ Microsoft Excel เซฟเป็นรูปแบบนี้ได้) โดยมีช่องตารางดังนี้

- รหัสประจำตัว
- รหัสผ่าน (โปรแกรมทดสอบกับรหัสเป็นตัวเลข 4 หลัก)
- ชื่อนักเรียน
- ชื่อวิชาที่ 1
- คะแนนวิชาที่ 1
- ...
- ชื่อวิชาที่ n
- คะแนนวิชาที่ n

โดยชื่อวิชาสามารถมี `(คะแนนเต็ม)` ต่อท้ายได้เพื่อให้ระบบคิดสถิติ และในไฟล์เดียวกันสามารถมีข้อมูลวิชาไม่เหมือนกันทุกแถวได้

สามารถกำหนดคะแนนเป็นตัวหนังสือได้เพื่อแสดงข้อมูล โดยต้องไม่ระบุคะแนนเต็มต่อท้ายชื่อวิชา

ตัวอย่างข้อมูล

```csv
11000,0001,นาย ก ขค,ภาษาไทย (50),0,ภาษาอังกฤษ (40),10
11963,1113,ด.ช. ฆ งจ,ภาษาไทย (50),40,ภาษาอังกฤษ (40),35
21000,5000,นส. ฉ ชซ,สังคมศึกษา (20),5,คอมพิวเตอร์ (20),15
```

## Design

ในส่วนนี้จะอธิบายถึงส่วนสำคัญต่างๆ ในการออกแบบโปรแกรม

### การรองรับโหลดจำนวนมาก

ในปัจจุบันการเชื่อมต่อ PHP บนเว็บโฮสต์ติ้งมักจะใช้ FPM ซึ่งจะมี thread pool และเว็บไซต์หลักของโรงเรียนก็มักจะเป็น PHP ที่มีการใช้ฐานข้อมูล MySQL เช่นกัน
เมื่อถึงเวลาประกาศผลคะแนน นักเรียนจะเข้าสู่เว็บไซต์เป็นจำนวนมากซึ่งอาจทำให้เว็บไซต์ล่ม ไม่ว่าจะเกิดขึ้นจากฐานข้อมูล MySQL ชนขีดจำกัดการเชื่อมต่อ
หรือ thread pool ของ FPM เต็มทำให้ไม่สามารถใช้งาน PHP ได้

ดังนั้น การออกแบบโปรแกรมนี้จึงกำหนดว่าจะต้องทำงานได้ในรูปแบบ single page application (SPA) โดยใช้ html ไฟล์เดียว ไม่ใช้ PHP ในส่วนหน้าบ้าน

ปัญหาที่จะต้องแก้ไขต่อมาคือการเปิดข้อมูลซึ่งจะต้องมีความปลอดภัย ไม่สามารถดูข้อมูลของผู้อื่นได้ ถ้าหากเป็นระบบ API ก็สามารถแก้ไขได้ไม่ยาก
แต่เนื่องจากข้อจำกัดว่าจะไม่ใช้งาน PHP จึงจะต้องหาเทคนิคใหม่ โดยเทคนิคที่ใช้ก็คือโปรแกรมจะแยกไฟล์ CSV รับเข้า เป็น 1 ไฟล์ JSON ต่อนักเรียน 1 คน
โดยตั้งชื่อให้ตรงกับรหัสประจำตัว ดังนั้นฝั่งผู้ใช้งานสามารถเปิดไฟล์ JSON ได้สำเร็จแสดงว่ามีข้อมูลถูกต้อง หากเป็น 404 Error แสดงว่ากรอกข้อมูลไม่ถูกต้อง

### วิทยาการรหัสลับ

สำหรับการตรวจสอบรหัสผ่าน เพื่อให้มีความปลอดภัยจึงตั้งชื่อไฟล์ JSON ที่แยกออกมาให้มีทั้งรหัสประจำตัว และรหัสผ่านอยู่ในชื่อไฟล์
หากเปิดไฟล์ได้สำเร็จแสดงว่ากรอกข้อมูลทั้งสองได้ถูกต้อง และเพื่อไม่ให้ข้อมูลรหัสผ่านหลุดออกไป รวมถึงกรณีที่มีการใช้ระบบแชร์คะแนนที่แชร์ชื่อไฟล์ออกไป

ในเวอร์ชั่นดั้งเดิม กำหนดให้รหัสผ่านผ่านแฮชฟังค์ชั่นโดยใช้ฟังค์ชั่น $`password_{hashed} = SHA1(username + password + fileid)[0:5]`$
โดย `fileid` เป็นชื่อไฟล์คะแนนที่ระบบสุ่มขึ้นมา

ทั้งนี้ความปลอดภัยในเวอร์ชั่นนี้ก็ยังไม่ได้ดีมากนัก เพราะ SHA-1 เป็นแฮชฟังค์ชั่นที่มีความเร็วสูง ส่วนรหัสผ่านมีเพียง $`10^{10}`$ แบบจึงสามารถ
ใช้การตะลุย (brute force) ค้นหารหัสผ่านจริงได้

ในเวอร์ชั่นที่เขียนขึ้นใหม่นี้มีการปรับปรุงให้ทันสมัยขึ้น โดยเปลี่ยนฟังค์ชั่นแฮชเป็น PBKDF2 ซึ่งมีความปลอดภัยมากขึ้นกว่า SHA-1 ที่ไม่ควรใช้งานแล้วในปัจจุบัน
และออกแบบให้ตรงกับลักษณะการใช้งานที่ใช้เพิ่มความแข็งแรงของรหัสผ่านโดยตั้งใจให้ทำงานได้ช้า
สาเหตุที่เลือก PBKDF2 เนื่องจากรองรับด้วย [Web Crypto API](https://w3c.github.io/webcrypto/#pbkdf2) เพื่อประหยัดขนาดของซอร์สโค้ดหน้าบ้าน
โดยกำหนดให้รหัสผ่านคือ $`password_{hashed} = PBKDF2(password, salt=fileid + "\_" + username, hash=SHA256, iterations=10000)[0:8]`$

ข้อจำกัดคือเนื่องจากการประกาศผลคะแนน ทางเซิร์ฟเวอร์จะต้องคำนวณแฮชรหัสผ่านของนักเรียนทุกคนซึ่งการใช้แฮชที่ช้าจะทำให้ระบบทำงานหนัก จึงเลือก
จำนวนรอบไว้ที่ 10,000 รอบ ซึ่งถือว่าต่ำมาก (เทียบเท่ากับความปลอดภัยของ iOS 4 ณ ขณะที่เขียนนี้ [OWASP](https://cheatsheetseries.owasp.org/cheatsheets/Password_Storage_Cheat_Sheet.html#pbkdf2) แนะนำที่ 600,000 รอบ)

### PHP

ปัจจุบันแม้ว่าภาษาสมัยใหม่กว่าจะได้รับความนิยมกันแพร่หลาย แต่โฮสต์ติ้งของโรงเรียนยังมักจะรองรับเฉพาะภาษา PHP อยู่ อีกทั้งภาษาใหม่ๆ ยังติดตั้งแอพพลิเคชั่น
ยากกว่า PHP บน Shared hosting โปรแกรมนี้จึงยังคงเขียนด้วยภาษา PHP

### Web Components

หน้าบ้านในเวอร์ชั่นใหม่นี้เขียนด้วย [Lit](https://lit.dev) ซึ่งใช้งานเป็น Web Component สามารถนำไฟล์ JavaScript ของโปรแกรมไปติดตั้งบนหน้าเว็บไซต์ใดๆ
และเอาโค้ด tag `<whs-score>` ไปติดตั้งเพื่อแสดงผลคะแนนได้เลย (ไม่จำเป็นจะต้องนำไฟล์ CSS ไปด้วย เนื่องจากมี CSS ในตัว)

เป้าหมายของหน้าบ้านเวอร์ชั่นใหม่นี้คือการรองรับเบราว์เซอร์สมัยใหม่ขึ้น (ที่ออกมาหลังจากปี 2021 เป็นต้นไป) ทำให้โค้ดมีขนาดลดลง

ในเวอร์ชั่นเดิม ขนาดของไฟล์ JavaScript และ CSS รวมกันคือ 539.43kB (ไม่บีบอัด)
